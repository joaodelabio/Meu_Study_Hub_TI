05 · Versionamento

Git na prática

$ git init -b main
$ git add .
$ git commit -m "feat: estrutura inicial"
$ git tag -a v1.0 -m "Versão 1.0"
$ git commit -m "feat: slides e histórico"
$ git tag -a v1.1 -m "Versão 1.1"
$ git push origin main --tags
  • Conventional Commits (feat, docs, fix)
  • SemVer com tags anotadas
  • CHANGELOG.md documentando cada versão
