05 | Versionamento

Versionamento com Git

$ git init -b main
$ git add .
$ git commit -m "feat: estrutura inicial"
$ git tag -a v1.0 -m "Versao 1.0"
$ git commit -m "feat: slides e historico"
$ git tag -a v1.1 -m "Versao 1.1"
$ git push origin main --tags
  • Conventional Commits (feat:, docs:, fix:);
  • SemVer com tags anotadas no repositório remoto;
  • Rastreabilidade de alterações via CHANGELOG.md.
