# 🎬 Roteiro do vídeo de apresentação (≈ 5 minutos)

> Dica: grave a tela com o **OBS Studio** ou a **Xbox Game Bar** (`Win + Alt + R`) e use os slides
> (`slides.html`, navegue com as setas ←/→) como apoio.

| Tempo | Tela | Fala sugerida |
|---|---|---|
| 0:00 – 0:30 | Slide 1 | "Olá, sou o João Gabriel de Labio, aluno do 8º semestre de Ciência da Computação do UniCEUB. Vou apresentar meu Study Hub, desenvolvido para a disciplina Bootcamp I." |
| 0:30 – 1:00 | Slides 2 e 3 | Biografia rápida e propósito: centralizar, versionar e mostrar minha produção acadêmica. |
| 1:00 – 2:00 | GitHub (repositório) | Mostrar as pastas `01_`, `02_` e `03_`, abrir o README principal e o README de uma disciplina. Explicar o padrão de nomes. |
| 2:00 – 2:50 | GitHub → Commits / Tags | Mostrar o histórico de commits, as tags `v1.0` e `v1.1` e o `CHANGELOG.md`. Explicar Conventional Commits e SemVer. |
| 2:50 – 3:50 | Site (GitHub Pages) | Navegar pelo site: hero, biografia, áreas de interesse, árvore de diretórios, matriz de disciplinas e histórico de versões. Abrir os slides. |
| 3:50 – 4:30 | LinkedIn | Mostrar o projeto na seção Projetos e no Em destaque do perfil, com o link para o repositório. |
| 4:30 – 5:00 | Slide 8 | Próximos passos (preencher as pastas ao longo do semestre) e agradecimento. |

## Checklist antes de gravar

- [ ] Repositório público e com GitHub Pages ativo
- [ ] Tags `v1.0` e `v1.1` enviadas (`git push origin main --tags`)
- [ ] LinkedIn atualizado
- [ ] Vídeo publicado como **Não listado** ou **Público** no YouTube
