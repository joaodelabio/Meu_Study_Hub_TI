## 📐 Padrão para novos projetos

Cada projeto pessoal deve ter sua própria pasta com um `README.md` contendo:

1. **Objetivo** do projeto;
2. **Tecnologias** utilizadas;
3. **Como executar**;
4. **Resultados / aprendizados**;
5. **Capturas de tela** (quando aplicável).
