## Padrao para novos projetos

Cada projeto pessoal deve conter sua respectiva subpasta com um arquivo `README.md` estruturado contendo:

1. Objetivo do projeto;
2. Tecnologias utilizadas;
3. Instrucoes de execucao e reproducibilidade;
4. Resultados obtidos e aprendizados;
5. Evidencias graficas ou capturas de tela (quando aplicavel).
